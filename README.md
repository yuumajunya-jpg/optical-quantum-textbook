## 今回追加した教材（v1.1.0）

[追加教材の学習案内を開く](教科書/00_学習案内.md)

`教科書` フォルダーには、本文 16 章、学習案内、付録 4 編の計 21 ノートを収録しています。
量子情報と光の基礎から、GKP、C4、ソフト復号、工場とオンライン処理の接続、雑音、統計評価、資源量へ進みます。
解答付き演習 20 問、原稿の数式ラベル 67 件との対応表、検算用 Python コードを含みます。
このフォルダー単独でも Obsidian の保管庫として開けます。

持ち運び用は [v1.1.0 の教材 ZIP](https://github.com/yuumajunya-jpg/optical-quantum-textbook/releases/download/v1.1.0/optical-quantum-textbook-v1.1.0.zip) です。
