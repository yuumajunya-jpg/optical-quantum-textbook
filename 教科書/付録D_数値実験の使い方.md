# 数値実験の使い方

案内：[[00_学習案内]]

## 検算の目的

`計算/verify_textbook.py` は、教材の基本式と原稿が報告した集計値の算術を検算する。
C4 工場の非公開シミュレーターを再実装したプログラムではない。
GKP の単一位相振幅の誤り率を計算しても、論文の Bell 資源誤り率を再現したことにはならない。

検算対象は、C4 安定化子と論理演算子、明示的な符号語、Hadamard と交換の合成、対応位置 CNOT、16 パターンのソフト周辺化である。
さらに GKP の奇数区間積分、巻き込み対数オッズ、Jeffreys と CP 上限、名目資源費を計算する。
Obsidian のノートリンク、見出しリンク、画像の存在、数式区切りの対応も確認する。

## 実行

Python と NumPy、SciPy を用いる。
未導入の場合だけ、利用する Python 環境へ次の依存を導入する。

```powershell
python -m pip install numpy scipy
```

`教科書` フォルダーを作業ディレクトリーにして実行する。

```powershell
python 計算/verify_textbook.py
```

検算に失敗すれば assertion で停止する。
成功時には `計算/検算結果.json` を書き出す。
主要な出力の目安は次の通りである。

| 計算 | 値の目安 |
|---|---:|
| $3/10^6$ の片側 CP 上限 | $7.7536\times10^{-6}$ |
| $4/10^6$ の片側 CP 上限 | $9.1535\times10^{-6}$ |
| $0/15000$ の片側 Jeffreys 上限 | $1.2804\times10^{-4}$ |
| $0/200000$ の片側 CP 上限 | $1.4979\times10^{-5}$ |
| CP 上限 $10^{-5}$ をゼロ失敗で満たす最小試行数 | $299572$ |
| $12\times288/0.95$ | $3637.8947$ |

## 変更して学ぶ

GKP の分散を変えて、判定境界の尾部がどれほど変わるか調べる。
`wrapped_log_odds` の $z$ を格子中心から境界へ動かし、信頼度が下がることを確認する。
演習 10 の $p$ を変更して、ゼロシンドロームで条件付けた確率と単純な物理誤り率を比較する。

統計の $n$ を増やすと、失敗ゼロの上限がほぼ $1/n$ に比例して小さくなる。
一方、失敗数を見てから $n$ を増やす停止規則へ変更した場合は、固定標本の保証をそのまま主張しない。
数式のパラメーター変更と、試験手順の変更を区別して学ぶ。
