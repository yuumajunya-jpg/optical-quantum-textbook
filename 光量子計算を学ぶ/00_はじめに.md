# 検証済み量子資源から光量子計算へ

この教材は、Fukuiほか **Modular optical fault-tolerant quantum computation via an interface between verified resources and online logical operations**（提供された arXiv:2610.32838v1 の `main.tex`）を理解するための日本語教科書です。論文の順序をいったん離れ、量子状態、光の連続変数、GKP、誤り検出、復号、光学実装、統計評価の順に学びます。

目標は、要旨を言い換えることだけではありません。「なぜその数式になるか」「何が測れて何が未知か」「何が実証され何が設計条件か」を自分で説明できるようになることです。線形代数・微積分を完全に習得していなくても読み始められますが、数式を追う際には第1章に戻ってください。

## Obsidianでの使い方

このフォルダを保管庫として開くか、既存の保管庫へフォルダごとコピーしてください。追加プラグインは不要です。数式は `$...$` と `$$...$$`、リンクは `[[ノート名]]`、図は `![[画像名]]`、解答は折りたたみコールアウトを使います。章末の「前へ・次へ」と関連リンクから読み進められます。

図と論文ソースは `assets` と `sources` に同梱しています。図は著者の原図であり、本教材の新規作図ではありません。原図内の略記より本文の定義を優先してください。原論文の再配布条件は元資料に従います。

> 公開された数式・論理ゲート・統計上限・会計式は追える構成です。一方、著者はデータとソフトウェアを一般公開しておらず、完全な回路別遷移表や学習済みパラメータも本文だけでは復元できません。したがって、教材だけで論文のMonte Carlo実験を完全再実行できるとはしていません。具体的な境界は [[23_参考文献と再現性]] に記します。
